## Блоки (одиниця = блок, порядок і залежності)
1. **B1 Каркас.** `dev-dashboard/` workspace (власні `typecheck`, `lint`), eslint-секція, `scripts/dev-all.mjs` (child_process, SIGINT/SIGTERM обом, без нових залежностей, без `pkill -f`), клієнт з `--strictPort` 5173, дашборд 5174. Тести: запускач (зайнятий порт, Ctrl-C), `npm ci` на чистому клоні.
2. **B2 Сервер.** Власний Node API, лише GET `/api/*`, bind `127.0.0.1`, перевірка Host/Origin/loopback, UI статикою. Тести: чужий Host/Origin 403, не-loopback 403, `/@fs/` недоступний, імпорт-guard (client/functions не імпортують `dev-dashboard`, hosting public = `client/dist`).
3. **B3 Збирач і знімки.** Одиниця = задача (унія `wf.task.id`, `ready-for-cpd/SPO-N`, незмерджені `SPO-N*`). Знімки `docs/reviews/dash/<task>.json` (відстежувані, без PII, схема з enum і ≤80 символів). Функція `selectBranchesToDelete` (git cherry проти задеплоєного SHA, ніколи main/чужі). Тести: схема, фікстура з токеном/email відхиляється, вибір гілок.
4. **B4 Hooks і журнал пауз.** Лог першим кроком у `wf-stop-hook`/`wf-context-hook`/`stop-guards`, тип події зі stdin, один append ≤1 КБ, `{ts,sid,kind,open,blocked,cat}`, ротація, завжди exit 0, нічого в stdout. Агрегація в знімки (зупинки, чесні блокери, компакції, нудж, медіана, розподіл по годинах). Тести: підроблений stdin на кожну подію, «немає wf.json → рядок записано», оновлення guard-тесту.
5. **B5 UI.** Мова «Dev Console» з канвасу: рейка з полицею cpd, Σ Overall, 8 вкладок задачі, смуга часу, панель Linear («Open in Linear» + «View here» з фолбеком на дані API). Англійська лише (R15). Власні токени-змінні, файли ≤600 рядків (guard).
6. **B6 Інтеграція dev.** `npm run dev` піднімає обидва, відкриває таб дашборда.
7. **B7 Закриття табів.** Таб зникає, коли Linear = Deployed to prod і гілку видалено (крок у `cpd` SKILL уже є).
8. **B8 Close-out.** Повторний інвентар `rg`, реєстр R1–R30 закритий доказами, базова лінія зелена, швидкість (pre-push ≤2 хв, CI ≤5 хв), рядок «ризики: N оцінено, N закрито, M знайдено по ходу, прогалин K».

Залежності: B1 → B2 → B3 → B5; B4 паралельно B2 (файли hooks окремі); B6, B7 після B5; B8 останнім. Спільні файли (`package.json`, lockfile, eslint-конфіг, settings hooks) править один виконавець.

## Дані, юридичне
Колекцій Firestore, rules, шифрування, R-рядків немає: дані лише локальні/в git. Згоди, Privacy Policy, процесори не зачеплені (немає зовнішніх запитів, крім Google Fonts у макеті: у продукті шрифти локально, без CDN). Моніторити PII у знімках (R23). Прод-дані не читаємо.
