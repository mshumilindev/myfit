# SPO-436 «Мої пристрої» — план розробки

Джерела: spike SPO-437 (`claude/SPO-437-sessions-registry-spike.md`, ADR 012), дизайн SPO-438 (канвас «Мої пристрої — дизайн», затверджено власником 04.11.2026: «давай як є в розробку»).

## Трасування

| Знахідка / рішення           | Екран дизайну       | Задача                | AC                                                              |
| ---------------------------- | ------------------- | --------------------- | --------------------------------------------------------------- |
| Тип пристрою на запису сесії | Мобільний / десктоп | Сервер: `kind`        | `deviceKind` з UA, записується при створенні й оновленні; тести |
| Зображення пристрою (силует) | Шард `DeviceImage`  | Клієнт: кіт           | примітив + сторі + тест + запис у UI-KIT.md                     |
| Чисті підписи, нові рядки    | Мобільний / десктоп | Клієнт: SessionsSheet | модель у назві, «місто · час», без «Остання активність»         |
| Новий вхід — помітний        | Банер зверху        | Клієнт: SessionsSheet | `Banner` для входу на іншому пристрої <24 год                   |
| Push про новий вхід          | —                   | Сервер: push          | ключ `signin`, лише коли вже є інший живий пристрій             |
| Миттєве відкликання          | —                   | Сервер+rules+клієнт   | `sessionState`, rules-тести, слухач                             |
| Місто/країна за IP           | —                   | GeoIP                 | **заблоковано рішенням власника** (ліцензія DB-IP, розмір)      |

## Екрани → код

`SessionsSheet.tsx` (Sheet, ListPanel/ListRow, Chip, Button, `Banner`, новий `DeviceImage`); `Banner.css` — `flex-shrink: 0` (не стискається в колонці Sheet).

## Дані й безпека

Нові поля відкриті (метадані пристрою, як `label`): `kind`. Нова підколекція `users/{uid}/sessionState` (rules: get власник, решта заборонено). R7 оновлено. Експорт/видалення: каскад видалення акаунта покриває `users/{uid}/**`; перевірити тестом каскаду (відкрито).

## i18n

`sessionsNewKicker`, `sessionsNewBody` (5 локалей); `sessionsSeen` прибрано; `push signin` (5 локалей). lt/et — вичитка носієм.

## Юридичне (`{{ЮРИСТ}}`)

Строк зберігання записів сесій; текст push і чи потрібна окрема згода; політика (`policyVersion`) через `kind` і `sessionState`; атрибуція DB-IP при GeoIP.

## Порядок

Сервер (kind, push, sessionState, rules) → клієнт (DeviceImage → SessionsSheet → слухач) → тести → гейт → `risk-reviewer` (rules, push) → браузер 390/1280.

## Відкриті питання власнику

GeoIP (DB-IP Lite, CC BY 4.0, ~десятки МБ у функції); фото/рамки замість силуетів (окремий ADR).
