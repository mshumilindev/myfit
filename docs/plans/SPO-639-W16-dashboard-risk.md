## 2. Чекліст категорій

- **Дані:** не зачеплено Firestore/vault/rules/експорт/каскад/міграції: дані розробки лише на диску розробника (`.claude/state`). Нові лише локальні файли (R3).
- **Формули й моделі (інв. 8):** не зачеплено (спортивних формул не торкаємось). Нові «формули» лише агрегати метрик дашборда (R10).
- **Ролі й права, згоди:** ні (ролі застосунку дашборда не бачать; користувач один: розробник). Згоди/Terms/Policy не змінюються: не збір даних користувачів, не передача (GitHub/Linear вже процесори розробки, не користувацьких даних).
- **Аддони:** не аддон; маніфест/`exclusion.ts` не чіпаємо; без аддонів поведінка Spotter однакова.
- **Офлайн/ідемпотентність/синк:** не зачеплено (Spotter). Дашборд сам: джерело недоступне (мережа/GitHub/Linear) → показуємо локальні дані + мітку «stale/ошибка джерела» (R10).
- **UI:** лише десктоп 1280+, тема Studio; 5 локалей не застосовні (R15); a11y: таби/таблиці з `aria`, фокус, клавіатура; нові примітиви лише на токенах.
- **Продуктивність:** бандл Spotter не змінюється (R1); час pre-push/CI (R8); hooks ≤ 200 мс (R4); сервер дашборда poll 5 с без важких git-команд (кеш).
- **Юридичне:** нова категорія персональних даних немає; у знімках заборонені email, імена, токени, тексти розмов (R3, R14).
- **Збірки:** PWA не змінюється, Electron-оболонка (`desktop/`) не тягне `dev-dashboard`, Storybook (сторі нових примітивів лише в дашборді).

## 4. План регресії

**(а) Базова лінія (прогнати до змін, має бути зеленою):** `npx vitest run tests/wf*.test.ts tests/kit-guard.test.ts tests/hygiene-ratchet.guard.test.ts tests/ci-metrics.test.ts tests/synthetic-stand.test.ts`; `npm run lint`; `npm run format:check`; `npm run typecheck`; `npm run deps:check`; `npm run deadcode`; `npm run i18n:check`; `npm run build -w client` + `node scripts/check-bundle-budget.mjs`.

**(б) Що не має змінитись:** вихід `wf status`/`report` (golden у `tests/wf*.test.ts`); бандл Spotter (gzip у межах `bundle-budget.json`, без `dev-dashboard`); `git diff` не торкається `client/src/**` (крім можливих сторі не маємо); hooks завжди exit 0 і те саме `decision` Stop-hook.

**(в) Нові тести на High/Medium:** R1 dist-grep; R2 сервер Host/loopback; R3 редакція/схема; R4 помилка запису/таймінг; R7 запускач; R10 агрегація, stale/помилка джерела; R11 без ключа; R12 вибір гілки; R16 deadcode.

**(г) Ручна/браузерна:** відкрити `localhost:5174` у Chrome (Playwright), пройти 9 розділів на синтетичних даних, перевірити що `localhost:5173` Spotter без змін; перевірити, що Spotter прод-збірка не містить дашборда.

## 5. Рішення, що чекають власника
