## Архітектура (чернетка, перевірити)

1. Планова функція раз на добу тягне межі з дозволеного джерела, валідує, пише версію в Firestore (журнал) і публікує GeoJSON у Cloudflare KV через API.
2. Worker читає KV з кешем у пам'яті ізоляту на ~5 хв. Порожній або биті дані: fail-open (рішення 30.10), без блокування.
3. Звільнення території = нова версія без цього полігона; Worker підхоплює за ~5 хв, без релізу.
4. До дозволу джерела: ручне версіоноване завантаження того ж запису (власні межі власника), той самий код читання.

## Блокери

- Дозвіл джерела (DeepState/ISW) або власні межі від власника: без цього автоматичний конвеєр не підключаємо.
- Секрет Cloudflare API для запису в KV (власник).
- Юрист: підстава гео-обмеження, режими ЄС/США, текст варіанта B (`{{ЮРИСТ}}`), вичитка lt/et.
