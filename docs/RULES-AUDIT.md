## 10. Відомі обмеження

- На цьому середовищі (Linux-VM з Mac-папкою) `tests/server-api.test.ts` не запускається: нативний `better-sqlite3` зібраний під macOS («invalid ELF header»). У CI (ubuntu) він працює; це лишилось у SPO-139.

`npm run metrics:stability -- --ref origin/main` (скрипт `scripts/stability-metrics.mjs`; потрібна історія git, не shallow). Показники по тижнях: частка фікс-комітів, відкати, фікси CSS/кіту («верстка зламалась знову»), rework (фікс файла, зміненого не-фіксом менш ніж 3 дні тому).
