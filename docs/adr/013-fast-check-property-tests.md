# ADR 013 — fast-check для property-based і fuzz тестів (SPO-66)

**Статус:** прийнято (04.11.2026).

**Контекст.** Помилки в стріку (SPO-42), автосні (SPO-43), межах дня й DST (SPO-152) були у чистій логіці й знаходились на прикладах, які хтось вигадав. Приклади не покривають усіх комбінацій (дні без покриття, нічні перетини, пояси з пів-годинним зсувом, DST).

**Рішення.** Додати `fast-check` (MIT, мейнтейнер dubzzz, активні релізи) як **devDependency кореня**. У бандл PWA і функції не потрапляє, використовується лише в `tests/properties.test.ts`: властивості стріку, сну, ваг, меж дня в шести часових поясах і fuzz парсерів неперевіреного тексту.

**Альтернативи.** Ручні таблиці прикладів (вже є, не знаходять нового); `jsverify` (не підтримується). Ціна: +~1 МБ у `node_modules`, +~1 с до прогону тестів.

**Правила.** Властивість, що впала, друкує мінімальний контрприклад і seed; його додають окремим звичайним тестом поруч із виправленням. Кількість прогонів (300) не знижуємо заради швидкості.
