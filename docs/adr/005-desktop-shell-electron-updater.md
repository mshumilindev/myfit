# ADR 005 — тонка Electron-оболонка десктопу й `electron-updater` (SPO-154, SPO-156)

**Статус:** прийнято (19.10.2026)

## Контекст

Старий `desktop/` був треєм над застарілим бекендом (Express+SQLite, `server/`) і не відображав продукт. Керівний принцип власника: уся розробка — у веб-застосунку (`client/`); десктоп — тонка оболонка без продуктового коду, зміни вебу доходять до неї самі (деталі й порівняння Electron/Tauri — у проєктних доках `SPO-154-macos-app-spike`, `SPO-156-windows-app-spike`).

## Рішення

1. `desktop/` — оболонка, що відкриває **хостований** застосунок (`https://spotter-64c3b.web.app`, перевизначення `SPOTTER_URL` для локальних перевірок). Вона не імпортує `client/src` і не запускає `server/`.
2. Безпека вікна: `contextIsolation`, `sandbox`, без Node у рендерері; навігація лише на origin застосунку, зовнішні `https`-посилання — у системний браузер; дозволи лише `notifications`, `media`, `geolocation` для origin застосунку.
3. Єдина поверхня для вебу — `window.spotterNative` (`preload.ts`, контракт у `shared.ts`): версія, нативне сповіщення, badge, відкриття зовнішнього посилання. Веб-код має feature-detect і працювати без нього (браузер/PWA).
4. **Нова залежність `electron-updater`** (прод-залежність `desktop`): автооновлення самої оболонки зі збірок GitHub Releases; зараз лише Windows (непідписана збірка), macOS — після підписання (SPO-157/162). Веб-частина оновлюється деплоєм хостингу й не потребує релізу оболонки. Ціна: ≈141 рядок у `package-lock.json`; `npm audit --omit=dev --audit-level=high` — 0 знахідок; у бандл PWA не потрапляє (залежність лише `desktop`).
5. Збірка: `electron-builder` через `npx` (не залежність); workflows `desktop-dmg`, `desktop-exe`, `desktop-release` — лише `workflow_dispatch`, непідписані; реліз створюється чернеткою й публікується вручну.

## Наслідки

- Підписання й notarization (macOS), сертифікат Windows, APNs-пуші — окремі задачі (SPO-157, SPO-159, SPO-162).
- Видалення `server/` і CI-джоба `smoke` (SPO-139) не залежить від цього рішення: нова оболонка від `server/` не залежить.
