# 002 — Перевірка Firestore rules на емуляторі

- Додано dev-залежність `@firebase/rules-unit-testing` 4.x, сумісну з Firebase 11.
- `npm run test:rules` запускає офіційний Firestore Emulator і окрему Node-конфігурацію Vitest без Firebase-заглушок застосунку.
- Ціна: Java 21 та завантаження емулятора для локальних перевірок; production-бандл не збільшується.
- Мета: перевіряти реальні правила доступу, а не покладатися лише на власний інтерпретатор правил.
