# SPO-221 · блок окупованих територій за координатами (висновок спайку)

Дата: 2026-10-29. Інженерний документ, не юридична консультація. Усе з джерелом; «не перевірено» означає, що я цього не підтвердив.

## Висновок

1. **Геолокація:** використовуємо координати, які Cloudflare Worker уже має безкоштовно (`request.cf.latitude`, `longitude`, `regionCode`; всі плани). Окремої бази IP (MaxMind/DB-IP) не потрібно. Точність Cloudflare для Криму й окупованих областей **не перевірено**: перевірка можлива лише з реальними IP після активації.
2. **Межі:** жодного джерела з підтвердженим правом автоматичного використання немає. DeepState не має документованого API чи завантаження і не вказує умов; третє-сторонні дзеркала (напр. github.com/cyterat/deepstate-map-data, GPL-3.0) не мають підтвердженого дозволу DeepState. Тому **полігони в репо не лежать**: Worker читає `OCCUPIED_GEOJSON` зі змінної середовища; вмикається лише коли власник отримав дозвіл або надав власні межі.
3. **Код:** `edge/geo-block/src/polygon.ts` (промінь, дірки, MultiPolygon, бите значення нікого не блокує) покритий тестами (`tests/geoBlockWorker.test.ts`). Тестовий «полігон» у тестах: груба коробка, не межа.
4. **Fail-open:** невідомі, мобільні та VPN IP проходять. Для легітимних українців це безпечніше; обхід документовано.
5. **Оновлення:** до отримання дозволу ручне, версіоноване оновлення змінної (раз на місяць). Автоматичний щоденний конвеєр (планова функція → валідація геометрії/розміру/різкої зміни → зберігання з журналом версій → алерт про застарілість → при збої лишаємо останню добру версію) описано, але не будується без дозволу джерела.

## Джерела й факти

- DeepState: сторінка без API/умов; у переліку ресурсів позначено «No download» (github.com/simonhuwiler/russo-ukrainian-data-ressources); оновлення можуть відставати на 2-3 дні (en.wikipedia.org/wiki/DeepStateMap.Live). Живий endpoint я отримати не зміг (403 від проксі): формат і частота **не перевірені**.
- ISW: «безкоштовно, але треба звернутись» (той самий список); умови не перевірені.
- Natural Earth: public domain (naturalearthdata.com/about/terms-of-use/); чи є окремий полігон Криму: не перевірено; окуповані області материка не покриває.
- MaxMind GeoLite2: безкоштовний, потрібен акаунт і атрибуція; «значно менш точний» за платний; з 1.12.2025 для України частіше порожні поля підрозділів/міста (dev.maxmind.com/geoip/release-notes/2025/). Платний GeoIP2 City: $148/міс (maxmind.com/en/geoip-databases). DB-IP City Lite: CC-BY 4.0. IP2Location LITE: безкоштовний з атрибуцією. Не потрібні, бо Cloudflare дає координати безкоштовно.
- Правове: ЄС обмежує неконтрольовані урядом частини Донецької, Херсонської, Луганської, Запорізької областей (Reg. 2022/263), FAQ Комісії не згадує загальні онлайн-послуги (висновок: інференс); OFAC: Крим і ДНР/ЛНР, питання безкоштовного застосунку для осіб не з'ясовано. Перед запуском проконсультуватися з юристом (рішення власника від 21.10: консультація до запуску).
- Приватність: IP не зберігаємо, Worker його не читає (Breyer C-582/14: IP може бути персональними даними).

## Рішення, ухвалені за власника

Fail-open; без вбудованих полігонів до дозволу джерела; Cloudflare-координати замість окремої GeoIP-бази.

## Що потрібно від власника

Запит дозволу в DeepState (їхні канали: Telegram, X, YouTube; контакту в документації немає) або в ISW; без цього автоматичне використання юридично неясне.
