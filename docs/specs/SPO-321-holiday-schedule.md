# SPO-321: графік святкових тем

Статус: код готовий (`client/src/themes/holidays.ts`, `holidayWatch.ts`), теми свят ще не додані в реєстр, тому нічого не вмикається, поки тема з `holiday: '<id>'` не зʼявиться.

## Правила

- Перевірка **лише на клієнті при вході в застосунок** (і опівночі, при поверненні у вкладку/фокус). Cloud Functions не потрібні, нічого не пишеться в БД.
- Вікно: **за 7 днів до свята і до кінця дня свята**; наступного дня повертається те, що було до того (збережена тема користувача).
- Вхід посеред вікна (наприклад за 3 дні до свята) ставить святкову тему так само. Вона **не зберігається** і не синхронізується: збережена тема лишається `committed`.
- Ручний вибір теми під час свята = «пропустити це свято цього року» (`gym.holidaySkip`, ключ `<id>:<рік>`); наступного року воно повертається.
- Дати за локальним календарем пристрою. Великдень: західний для всіх, православний для локалі `uk`. Різдво 25.12 для всіх. Якщо вікна перетинаються, перемагає найближче свято.
- Святкові теми не вибираються вручну, не в списку, не в анонсі, без «New»; кожна зміна грає анімацію перемикання нової теми; не під час тренування/документа/чату (тихі зони, повтор кожні 3 с).
- День незалежності на паузі (24.08 лише плейсхолдер; залежить від регіону, потрібне рішення власника).
