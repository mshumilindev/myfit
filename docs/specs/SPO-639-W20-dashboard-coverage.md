## Висновок
Макет v2 покривав приблизно половину правил: потік, паузи, прогони, CI, якість. Не вистачало саме «процесу»: документів spike→план зі станами, DoD, порядку робіт, дисципліни Linear, дозволів на реліз і попередження про відставання localhost. Усе додано в макет. Відкрите одне: чи показувати активних паралельних агентів (немає надійного джерела даних у git чи wf, потребує рішення власника).
