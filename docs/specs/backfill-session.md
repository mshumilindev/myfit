# Spec: Backfilling сесій (запис заднім числом)

Користувач тренувався, але не логував (телефон сів, забув). Він має змогу
створити сесію на минулу дату/час і наповнити її вправами так само, як
редагується будь-яке минуле тренування (режим S-30).

## Уже існуючий шлях (без змін)

- Нагадування «незалогований візит у зал» → **Log it** створює сесію на час
  візиту (`logVisitAsWorkout`) і відкриває її на редагування.

## Новий шлях: ручний backfill

Точка входу: Today → лінк **Log a past session** (під головною кнопкою).
Відкриває шіт у стилістиці S-21/S-39: дата, час початку, тривалість.

## Acceptance Criteria

1. **AC-1 · Створення.** Заповнивши дату (native date), час початку (native
   time) і тривалість у хвилинах, юзер тисне Save → створюється ОДРАЗУ
   ЗАВЕРШЕНА сесія (`finishedAt = startedAt + duration`, `autoFinished =
false`) і відкривається в режимі редагування минулого тренування, де
   вправи додаються кнопкою **Add** (не «Log», без rest-таймера).
2. **AC-2 · Валідація.** Save заблоковано, поки: дата/час у майбутньому;
   тривалість поза межами 1–480 хв. Порушення показуються інлайн-текстом
   ruby (без тостів — правило дизайну W-02).
3. **AC-3 · Дефолти.** Дата = вчора, початок = 18:00, тривалість = 60 хв.
4. **AC-4 · Ідемпотентність.** Сесія їде на сервер через чергу тим самим
   upsert-механізмом (id — клієнтський UUID); повторна відправка черги не
   створює дублікатів. Працює офлайн.
5. **AC-5 · Наслідки.** Backfill-сесія зʼявляється в Recent, тижневій
   стрічці, Progress і історії вправ нарівні зі звичайними; порядок Recent —
   за `startedAt`. Вона НЕ стає «відкритою» і не конфліктує з активною
   сесією (правило «одне відкрите тренування» не зачіпається).
6. **AC-6 · Видалення.** Як у будь-якого минулого тренування — діалог
   «Delete this workout?» з описом втрати (S-31).
7. **AC-7 · i18n.** Усі нові рядки — одразу в 5 локалях (en/uk/pl/lt/et).

## Поза скоупом

Довільне редагування часів уже збереженої сесії (є `updateWorkoutTimes` на
сервері/сторі, UI — окремою фічею); backfill із шаблону.
