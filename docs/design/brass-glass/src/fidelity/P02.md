# P02 · Widget library: fidelity map (pass 3, production-ready)

Script: `p02_widgets.py`. It produces **15 artboards**, listed in the Boards table below. Board heights are fitted to the measured content (`scratchpad/p02_heights.json`).

**Source of truth:** the app code. This covers `client/src/today/widgets/*.tsx` + `*.strings.ts`, `components/ui/Widget.css`, `WidgetGrid.css`, `ShortcutTile.css`, `today/shortcuts.tsx`, `today/WidgetLibrary.tsx` and `today/library.css`. The canvas library (T0, L0–L11, K1) is the design origin. **Where the two differ, the code wins.** The differences are listed below.

**Music:** music-canvas `V2-Widgets` only. Music is not in the Today widget code.

## Frame (Widget.tsx twin, `W()` in the script)

| Part | How it is drawn |
|---|---|
| Kicker | 10.5 px caps, in the family's tone text colour. Neutral family → muted. |
| Badge | 12 px muted, or a delta / tone text. |
| Headline | Value **28 px (t-num)** with a 13 px muted unit, then a 16 px name, then a 12 px sub (nowrap with ellipsis, as in the code). |
| Body / footer | `bodyLast` moves the body under the headline. Otherwise the headline sits at the bottom (margin-top auto). The footer holds buttons or stats. |
| Sizes | S 171 × 150 min, L 358 × 150 min, XL 358 × 330 min (grows like `aspect-ratio: 1` with content), M 358 × 64. M = 36 px tone IconTile, 14.5 px title, sub, then a trailing element or chevron. |
| Hierarchy | The loud element per widget is the element the code sizes up. That is the 28 px value, rings (84–150 px), bars in the family tone (rest neutral-800), bodymap heatmaps, the barbell, the moon and real photos. Labels stay quiet (muted 12 px, caps kicker). |

## Code vs canvas: differences (code wins)

- **111 widgets in code vs 115 in the canvas.** Nearest gym, Gym visits, Kit evidence and Gym bests (canvas L8) are not in the code. They are dropped, and Cardio & gyms has 8 widgets.
- **Canvas "Ask Atlas by voice" → code `atlas-quick-ask`,** "Ask Atlas · one tap". It is a tap-to-ask tile with chips, not voice.
- **Group names and grouping follow `WIDGET_GROUPS`.** Canvas L3/L9/L10 Apex / Learn / Atlas are regrouped into Apex (10), Learn (5) and Atlas (8). The canvas Body metrics widgets join Body & recovery.
- **Shortcuts:**
  - Canvas "Program day…" is not in the code.
  - "Rest day" is renamed "Day off" in the code.
  - The health group adds Next lesson, Ask Atlas and Weigh-in.
  - Activity order and tones follow `ACTIVITY_TYPES`.
  - States: live shows the meta "24 min" and a tone dot, not the canvas "Run · 24:10".
- **Tones:** canvas Apex purple, Learn pink and Atlas coral are now their real tokens (apex / learn / atlas), no longer mapped to sleep / bad.
- **Content follows the code strings** (`*.strings.ts`), e.g.:
  - Streak XL = ring 130 + "Open Apex".
  - Awards L has the next-award progress line.
  - Discover "• Daily" markers are kicker text "Daily" as in the code.
  - Goals archetype "Lean Athlete / Conditioned and defined" replaces the canvas "Athletic".
- **Images only where the code shows them:**
  - Physique goal, gyms, last route and cardio machine have **no** picture in the code, so none is drawn.
  - Atlas portraits are not used by any widget.
- **Plate calculator:** the code draws one side (BarSide). The board uses the kit's full `barbell()` with the same per-side plates.
- **Music (P02-14) is not in the app code.** It is kept from V2-Widgets as the source of truth for music.

## Remaining approximations

- **Progress photos** are the user's own runtime photos, with no local file. They are drawn with the kit `photo()` placeholder captioned "Your photo".
- **RaceChart (Beat last week XL):** last week's line is drawn solid neutral. The code draws it dashed; `spark()` has no dash.
- **Charts** use kit `spark` / `bars` without axis guides where the code has none.
- **WidgetList rows** have no hairline dividers. Borders are not allowed inline, and the kit list row is too tall.
- **Long subs and M titles are ellipsized** (nowrap + ellipsis, as in Widget.css). Some M rows show fewer words than the canvas.
- **Pixel grid (Year in pixels L/XL):** the 53 × 7 cells are about 4.7 px, as in the code, so they read as fine texture.
- **Night mode and role variants:** none. The widgets have no role-dependent rendering, except the Learn catalogue picked by role.

## Images needed that are not in ASSETS.txt

None are required. Optional: sample progress photos (two user-style shots, e.g. `progress/sample-1.jpg`, `progress/sample-2.jpg`) would replace the two `photo()` placeholders.
