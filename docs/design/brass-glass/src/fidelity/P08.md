Key source facts

- Programs / Playbook are Overview drill-ins: top is `‹ Overview` (OverviewBack), tab bar active = Overview. The old peer switcher no longer renders.
- Roles: `isCoach = trainer || admin`. Coach-only: program tile members button (AvatarStack or "Assign"), members drawer, builder menu item "Assign to members".
  Trainer loads `trainerClients`, admin `adminPeople` — same UI, different people. Members never see these.
- Mobile builder = 4 steps (basics → week → day → review); desktop = one page, 3 columns. Review is also the landing screen of a saved program.
- Starter flow: Today "Suggest a program" → sheet (P01-ProgSuggest) → toast `progSuggestCreatedToast` → ProgramsView opens the builder on step **week** with the seeded draft (weekday names as day names).
  (starterPlan.ts's empty-session starter is part of SessionView and is drawn on P04-Session-Empty.)
- ProgramAssignDialog (PG-03) exists in code but no screen mounts it today (members drawer replaced it) — drawn once, titled "unmounted".
