# P10 · Health, sleep, injury — fidelity map

Script: `p10_health.py` · 91 artboards · sources = `client/src/views/HealthView.tsx`, `views/health/{HealthForm,HealthHistory,parts}.tsx`,
`views/SleepView.tsx`, `components/{SleepAutomation,SleepHero,MoonGlyph,Readiness,MuscleStatePanel,FixSheet}.tsx`, `views/InjuryView.tsx`,
`App.tsx` (night mode, SleepHero placement, tab bar hidden on overlays). Strings = `client/src/i18n/en.ts` (placeholders filled with mock data:
Mykola · Iron Temple · Mon 28 Sep 2026 · last night 23:40–06:52 = 7h 12m · live night since 23:40 = 6h 48m · Right knee rehab).

Rules applied
- Health, Sleep, Injury and every form are overlays: brand bar on top (App.tsx `.app-brand` always renders on mobile), **no tab bar** (`showTabbar = !activeOverlay`).
- Durations use the app's `fmtDurationHuman` format (`7h 12m`, `45m`), dates use `health/parts.tsx` formats (`Mon 28 Sep`, `14–17 Sep`, `26 Sep – 2 Oct`, `Fri 25 – Sun 27 Sep`).
- **Night mode**: while a night is live, App sets `data-sleep='night'` and mounts `SpotterSky` → drawn with `mood='sky'` (kit flips every token).
  SleepHero (`sleephero()`) sits under the brand bar on every screen except Sleep. Live-night screens: Sleep night, discard, wake, wake picker,
  backfill / schedule opened during a live night, auto-dim prompt (its scrim has class `night`), plus row 7 night variants of Today, Overview, Gyms,
  Health, a sheet, a dialog, paused hero and desktop. After "Log & wake up" the night is closed, so the logged card is day palette (`mood='sleep'`).
- Roles: none of these files branch on role (`tabsForRole` returns the same three tabs for everyone) → no role variants.
- Colour = the app's families (components/ui/tones.ts, Health.css): full rest `rest` (sky), active recovery `active` (teal), illness `illness` (amber),
  injury `injury` (coral), sleep `sleep`, accent brass only for neutral primaries — in list icons, Now blocks, calendars (endpoint + preset chips), timeline
  bars, filter dots, check marks and the tone-filled primaries (.p-rest / .p-act / .p-ill / .p-inj). InjuryView's `.rx` uses `--dgr = --color-danger`,
  so the rehab setup/plan boards stay `danger`/`bad` (as the app); Health's injury rows use `injury` coral.
- Hierarchy (pass 2): Health home → the "Now" group is e1 (family-tinted block, 28 px Stage/Day figure, stage progress, the action) and the rest stays
  flat grouped lists; forms → the Dates group with its calendar carries the screen, tone-filled primary; Sleep night / wake / logged → 56 px duration
  (app 44–52 px), centred, nothing else competes; Sleep hub → the two stats as the one hero; rehab plan → the current stage is a big danger block, other
  stages one-line rows; gym detail (P11) → 230 px hero.
- Anatomy: kit `bodymap/bodypair` (the app's body-muscles paths) for the readiness map (paint = READINESS_COLOR: recovering danger, nearly accent,
  ready ok, stale kcal), readiness rows/strip (MuscleIcon crops by GROUP_VIEW/GROUP_REGION), the muscle drawer figure, FixSheet MuscleSetChips,
  session muscle chips, and the injury "Good to know" card.
- MoonGlyph: drawn from MoonGlyph.tsx paint (dark disc #1a2036, lit radial #f6f6f2→#dee0e5→#b2b5c2, four maria, limb shadow, halo on auto-dim) via
  `swatch()` discs; phase from moon.ts for 28 Sep 2026: waning gibbous 97 % (night), full moon 98 % at 23:00 (auto-dim) → lit limb left.
- Night palette: live-night screens `mood='sky'`; the logged card uses `mood='moon'` (`.sleep-screen` paints with the --s-* moonlit tokens but no sky).
