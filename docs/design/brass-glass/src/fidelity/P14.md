Key source facts applied
- The user's own profile lives in the **People** sub-app (RosterApp, tab `me`, `embedded`): header `spotter · Me|Clients|Users` (role label), bell, full LanguageSelector (flag + English + caret), no MasteryBadge;
  nav = [Clients (trainer) | Users (admin)] · Me · Apps. Member/Trainer/Admin boards differ exactly there (+ trainer meta shows `Clients: n`).
- Other people's profiles open non-embedded inside People (back caret). Admin: editable First/Last/Username + Cancel/Save, Settings tab → access list, Assigned trainer
  (Assign trainer; + Assign clients when the person is a trainer), Trainer privileges switch (not for self / admins). Trainer: read-only (`@username`), `Training now` pill,
  TrainerLivePanel, Settings tab renders nothing for a trainer viewer (so not drawn), Body tab read-only without badge.
- Gym overlays (Notifications, Settings) have **no tab bar** (`showTabbar = !activeOverlay`) but keep the brand header.
- Settings is admin-only (overlay guard `role !== 'admin'`), entry = desktop rail gear (admin only). Flags drawn = the two with copy (gymPresence, nutrition).
- Apps switcher order: Gym · Apex · Nutrition · People(label/desc per role) · Learn, then Sign out and note. Nutrition flag OFF → “Coming soon”, no chevron, not tappable.
- Sign-out ConfirmDialog body: queue (`signOutQueueBody(3)`) vs clean (`signOutCleanBody`); used by both ShellLauncher and Profile › Settings.
- Skins: every People-app board (Me / Body / Settings tabs, other users' profiles, their sheets, dialogs, avatar states, desktop Me) uses `skin='roster'` (silver).
  The Apps switcher boards are NOT skinned: styles.css gives each tile its app's own gem (.shell-ic-gym brass, -apex amethyst, -people silver, -nut lazurite, -learn rubellite) and the kit skin would repaint the Gym plate silver; only the sheet's silver head/pill chrome is approximated.
  Gym overlays (Notifications, Settings, Physique, toasts, sync card) stay brass. Nutrition is only a tile (its app is not staged), so no `skin='nutrition'` board.
- Night: Gym screens → `mood='sky'` + SleepHero; People app → `mood='moon'` (no sky, no SleepHero — RosterApp returns before SpotterSky/SleepHero).

## Pass 3 — hierarchy, production assets, colour coding, completeness (styles.css now read)
Hierarchy (from styles.css):
- Profile: `.profile-hero` is the e1 block → `card(tone='hero')` with a 124 px brass ring avatar, 24 px name (`t-h1`), then 12 px meta (`profile-meta-grid`, one wrapped quiet line).
  Stat cells follow `.profile-stat-cell` (min-height 104, value first in `t-num`, small icon top-right, `.accent` = brass ring → glass). Recent sessions and settings rows have no surface.
- `.profile-setting-row` (49 px, hairline, 17 px neutral-500 icon, no surface) → `card(tone='quiet')` rows; Sign out = danger row. Access rows are small surface pills (`.access-row`).
- Corrections from CSS: `profile-editing` has NO CSS → detail fields (First / Last / Username + Cancel/Save) are ALWAYS visible to self and admins (Edit only toggles to Done);
  `.profile-self:not(.profile-password-editing) .profile-security {display:none}` and while password-editing the Settings title, LanguageSelector and settings rows are hidden (Sign out stays) — P14-Me-Password redrawn that way.
- Body tab: `.bm-hero` (accent-900 gradient, 40 px weight) is the e1 block → hero + `t-hero`; Add weight is a left-aligned button (not full width); entries are quiet rows; delta down = ok, up = neutral.
- Notifications: RecapBlock hero is the loud block; `.notif-row` has no surface unless unread (faint accent surface + glowing dot). Kind colours exactly per `.nkind-*`: standard/feat/streak accent, pr/volume ok, trend kcal, challenge/atlas neutral.
- Apps switcher: `.shell-head` 11 px uppercase label (not a title), tiles are separate 16 px-radius surfaces with 48 px gem plates and 17 px bold names, locked tile dimmed without caret, Sign out = full-width danger button, 12 px note.
- Settings (admin): each `.settings-row` is its own surface with name / desc / switch.
- Notice / UpdatePlate: one family — surface, accent icon, dismiss / Reload.
Production assets:
- Physique picker uses the real `physiques/<id>.png`, and `<id>-lit.png` for the picked card (`.phys-card.active` accent surface + check). Added P14-Physique-Male-Picked (V-Taper lit).
