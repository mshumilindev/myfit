# P04 · Session — fidelity map

Script: `p04_session.py` · 80 artboards · source = `client/src/views/SessionView.tsx` (+ the components it mounts), strings = `client/src/i18n/en.ts`.

Key source fact: `const focusMode = true` — **Focus is the only live-session view** on a phone (one exercise / group per step,
Back / Next). The classic list (collapsed cards, QUEUED header, floating glass pill with discard / settings / + / map / finish,
live energy counter) renders only when the session is not live (past or auto-closed) or on desktop. So the live boards are all focus view,
and the auto-closed board is the classic view.

Typeable times (owner rule: every changeable time/duration can be typed) — `timein()`

- Rest target: typed field between −15 / +15 on every rest card; Rest sheet has the REST_PRESETS chips + a typed Target field.
- Static-dynamic ghost: the Hold, s well holds a typed time; cardio entry editor: Duration typed; new P04-Edit-Hold: a logged hold's time typed.
- Past-session start/end times are edited in the past-session editor (P06), not on P04.

Production-ready (rule #0c)

- Real images (`img` / `exercise_pic`): exercise photos 0.jpg/1.jpg as Start/End in the focus card (.ex-photos; one frame when a lift has one photo,
  nothing when none), picker rows/cards/tiles, suggestion tiles, empty-start hero + tiles, playbook rows, options-sheet thumb, exercise detail frames + swaps,
  photo slider; markers/warmup.jpg + markers/cooldown.jpg on marker cards; equipment/cardio-treadmill.jpg on the cardio card; equipment/barbell-olympic.jpg in the
  equipment picker + kit tray; home-hero.webp behind the home-set LiveHero; atlas/atlas-1.webp on the Atlas jab. Lifts without a staged photo show the app's
  own no-image barbell tile (xp-noimg), as the code does. LiveHero / past hero keep the house pattern (GymThumb is fetched at runtime).
- Mock exercise names switched to catalogue names that have photos: Cable crossover, Dips - Triceps Version, Pushups, Bodyweight squat.
- Anatomy: SessionMuscleMap heatmap = `bodypair(paint=zones)`; MuscleInfoDrawer = `bodypair(primary=chest)`; picker family tiles = FamilyFigure → `bodymap`
  painted in the family's readiness colour. ExerciseDetail (ⓘ) and the worth meter draw no figure in the code, so none is drawn.
- Colour coding from code/CSS: set-type colours (styles.css :root) warm-up #6aa7e8 → rest, drop #b58cf0 → apex, reverse #4fc1c9 → active, static-dynamic
  #e98bb8 → learn, failure #ff7a45 → injury (entry card tint + title, row kind text, F / F? tags, fail note); PR tag + record row = accent (brass), PR-attempt

  rgb(240,113,79) → injury; readiness (recovery.ts) recovering danger / nearly brass / ready ok / stale kcal; zones (volume.ts) under grey / productive ok /
  high brass / over danger; plate colours (plates.ts) and band colours (loads.ts BAND_HEX) via `swatch`/`barbell`.

Hierarchy (rule #0b, from styles.css)

- `.session-focus .live-rest, .session-focus .muscles-worked { display:none }` and `.session-focus .session-rail { display:none }` →
  the Current / Rest plaques, the Muscles-worked strip and the left dot rail are NOT drawn on live boards (they only exist in the
  non-focus list, e.g. the auto-closed board keeps Muscles worked). The step bar (`.plan-segments`, 4 px, 3 px gap) does that job.
- `.focus-view .exercise-card .start-next { display:none }` → no "Start next" button in focus; `.drag-handle` hidden too.
- `.live-hero.session-live-hero { height: 72px }`, timer 20 px, back button absolute over the left edge → `livehero(kind='session')`
  full-bleed in `phone(top=…)` under the brand bar (and SleepHero at night).
- `.focus-view .exercise-card` has no background/border/padding → the card is `card(tone='quiet')`; name 23 px; chips a quiet strip;
  set rows 16 px with 11 px index and 10 px kind/tags; `.set-rest` 10 px rest-blue right-aligned; stats strip 18 px + 10 px labels (e4).
- `.focus-view .gset` = brass liquid glass, float shadow, filled accent Log → `setentry()` = e1 on every set-logging board
  (wells, no left indent, big values). HoldWatchSet (`.gset.kind-hold`), the running cardio timer and the active CircuitBlock
  (`.circuit-block` accent ring + `.cb-cta`) are the e1 on their boards; the PR card (`.pr-card`, accent wash, 28 px main) is the e1
  while it shows (ghost hidden); the Empty-start `.es-hero` (accent ring) is the e1 there.
- `.rst-card` (e2): glass rest tint, 104 px ring, 26 px countdown; done = success tint + GO. Tired / Next-up banners
  (`.tired-banner`, neutral-900) and the superset strip (`.fss`, neutral-900 + accent edge) are e3; fail note, hints, meta are e4 lines.
- Plate calculator: `barbell(per_side=(25, 15))` + `plates_legend()`; Solve/Build, Target, total, Per side, Bar, kg/lb, Collars kept.
- Sheets/dialogs: at most one focal (the primary button / the wells); everything else plain rows.

Shell, night, roles (KIT_RULES "Shell, roles and night mode")

- Shell: App.tsx renders `.app-brand` on mobile above every overlay, so every session board starts with `brandbar(app='Gym')`; the compact
  LiveHero is hidden while the session overlay is open (`activeOverlay?.screen !== 'session'`), only the session-mode hero shows.
- Night: App.tsx shows `<SleepHero>` whenever `nightLive && activeOverlay?.screen !== 'sleep'` — i.e. also over the session, between
  the brand bar and the session. SleepPauseController pauses the night whenever you are off the sleep screen, so it is drawn as
  `sleephero(paused=True)` ("Paused · not counting"), on `mood='sky'` (SpotterSky is mounted app-wide while a night is live).
- Roles: the only per-role output in the session code is `canAuthor = getRole() === 'admin' || 'trainer'` in AddExerciseSheet →
  NewExerciseSheet note (newExerciseAuthorNote vs newExerciseNote; trainer/admin also publish to the shared catalogue). Drawn as
  Create exercise · Member / · Trainer / · Admin. Everything else in the session is identical for all roles (the trainer's view of
  a client's session is TraineeSessionView — P16).
- Music: P04-Music is titled "Session · Music (planned, V2)" — from the approved Music V2 design, not from current code.

Rules applied

- Order of every screen follows the JSX order: LiveHero → back button → stats strip → live-rest (Current plaque, Rest strip) →
  Muscles worked → focus step segments (+ dashed add) → circuit banner → card → focus nav (discard · back · Next · finish).
- Card order (renderCard): head (drag handle, name, prev / kind, plan count) → chips (equipment button, SidesChip, muscle chips) →
  start/end photos (focus) → progression hint → `# Reps Kg` header → rows (rest line before each set, reps, kg, tags @RPE / ~est / F / F? / PR,
  trash) → rest card or PR card → ghost set (GhostSetRow / HoldWatchSet) → tired / next-up banner → Start next → ghost hint.
- Copy = en.ts strings, placeholders filled with standard mock data (Chest 2 · Iron Temple · Bench 100 × 5 PR · 28 Sep).
- Removed from the previous version (invented): the dock (Add exercise / muscle map / focus), Skip / "+15 s" rest buttons (source: −15 / +15 only, no Skip),
  "Keep · rest 3:00", "Next set drops 5 %…", my discard copy, the "Energy" stat cell, offline banner + "Sync" row, "Queued" set tags,
  per-side L/R note card, swap-sheet "% match" list, invented machine-details sheet, picker loading skeleton + failed card, plate "Collars 2.5 kg each" row,
  rest "Sound · Chime over music", circuit "What you did" card, the timed-hold "Timed hold" tag, focus-mode "PR attempt" pill in the header.
