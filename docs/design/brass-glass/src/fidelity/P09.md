Approximated

- Body silhouette (MuscleBodyFigure) → figure placeholder; phosphor icons → nearest kit icons (bookmark → book).
- Band colours are physical swatches (BAND_HEX) — drawn with the nearest kit tone dots (yellow→brass, green→ok, red→bad, black→neutral…).
- Photos / thumbnails → kit photo placeholders; instructions text and exercise lists are mock catalog content.
  Not drawn: Learn "feed" tab (NotificationsView embedded — drawn on its own page); lesson reveal sentinel; lightbox zoomed state.
  Source has no loading/failed states for the gallery (bundled static data) or Learn (static catalog) — none invented.

#d1495b, #2b2f36 + the 10-colour picker); emerald for record / available / "here"; ruby only for "Needs … not at your gym" and removal.
