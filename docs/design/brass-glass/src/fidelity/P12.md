Rules applied
- Coach is an overlay (`activeOverlay.screen === 'coach'`): no tab bar; the mobile app-brand header (spotter · Gym · Mastery · bell · language) stays on top (App.tsx renders it for every overlay).
- Tempers are the three in the code (1 Warm / 3 Blunt / 5 Merciless = green / yellow / red → kit tones ok / brass / bad). The face ring and TemperHeat bars take the temper tone.
- Thread order = JSX order: atl-head (back · face → portrait · Atlas · temper / role [· softer today] · TemperHeat · settings) → PlanCard (main coach only) →
  older-sentinel → day groups (Today / Yesterday / weekday date) with notice / me / atlas items (N new marker before first unread, unread dot, time,
  chart, Do it / Cancel, 👍/👎 on newest answer, follow-up chips on newest answer, Puter chips, language chips) → welcome (empty chat) → composer.
- Roles: CoachView renders nothing per member/trainer/admin role. The only audience variant is "you have a human coach" (`useSelfTrainerId`) — drawn as
  Setup-Role-HumanCoach and Settings-HumanCoach.
- Skin: Gym brass (the coach is a Gym-app overlay). Night: Thread-Night keeps `mood='sky'` + SleepHero — the chat opens inside the Gym shell, where App.tsx renders SpotterSky and SleepHero.

## Approximated
- AtlasFace portraits (atlas-N.webp) → kit `atlas_face`; temper colour shown as a ring around it (kit face keeps its own coral hairline).
- 👍 icon: the kit has no thumbs-up — drawn with `check`; 👎 with `thumbdown`. Send (arrow-up) → kit `up` icon. Sign-out icon → `logout`.
- Composer drawn as a floating field + send button at the bottom (kit field).
- Year picker ‹ › and height − / + are kit chips (source: atl-chip buttons).
- Chat answer texts, the did-you-mean list and `startChips()` come from atlas/intents (not staged): answers are mock data built from standard values; the welcome
  chips use the en.ts atlasSuggest* strings. Tempers board shortens the welcome text with "…".
- Progress › Atlas: the TrendsView cards that follow "The numbers" belong to the Progress page and are not repeated here.
- Portrait: full-bleed image approximated with a large face on a double scrim.

- Mid-session jab (voiceNow) — lives on the session screen (P04).
