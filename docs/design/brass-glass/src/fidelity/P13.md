## Approximated
- Phosphor icons → nearest kit icons (flag-banner → target, medal → star, stack → layers,
  barbell → dumbbell, fire → flame, calendar-check → calendar, scales → scale, heartbeat → pulse, person-simple → body, export → share, copy → link).
- ByDay strip → kit `heat()` (intensity-shaded 7-wide grid). Confetti → kit dots. Share canvas preview → a glass card with the same drawn fields.
- Future week dot → dashed mini card. Rank tier cells: achieved = ok card, next target = glass card.
- Level thresholds computed as ratio × 82.4 kg rounded to 2.5 (source uses its own reference bodyweight).
- Detail sheet is a full-screen portal in the source; drawn as a glass panel over a dark scrim.
