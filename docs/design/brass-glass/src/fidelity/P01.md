Script: `p01_today.py` · 44 artboards (row 0 main flow · row 1 night + states · row 2 sheets · row 3 dialogs + desktop). Every title ends in · Member / · Trainer / · Admin.
Sources:

- Today Configurator canvas `artifact-files/ef716377-…/project/`, page **v3** (the launch page): T1–T6, A1, A2, D1, D2, K2, K3. v1 `Main` and v2 `B1`/`B2` are older versions of the same screens, and v3 replaces them (see "Superseded" below).

- Strings: canvas copy on the canvas boards. Everywhere else the strings come from `en.ts`, with mock values filled into the placeholders.

Values: the canvas values are kept as they are (Thursday, October 1 · Chest 1 · MS - 6 days · "2 of 6 sessions · Assigned by coach" · Kate / Valeriia / Konrad / Oleh / Marta / Andrii · 82 % · 8 h 30 m). The canvas has a 6-day program ("day 3 of 6", "26 planned"), and swapping in those names would break it.

## Follow-up · shell, roles, night mode, and today/ code (code wins)

**Shell:** the kit `brandbar()` (spotter · Gym · Mastery 640 · Notifications · Language), `phone(tabs='today')` (Today · Overview · + · Gyms · Apps), `desktop()` (AppRail) and `sleephero()` are used on every board.

**Roles** (TodayView `getRole()`):

- **Member:** Atlas solo strip. P01-Today, P01-Edit, P01-ConfigAtlas-Member (no clients → Atlas view only), and every other board titled · Member.
- **Admin:** the Atlas block is TrainerClientsStrip, Atlas first then clients, and `hasClients` unlocks the client options. Boards: P01-Today-Admin, P01-Edit-Admin (tag "Core · Together"), P01-ConfigCore (the full Atlas & clients sheet), P01-Atlas-Variants (client variants).

**Night** (mood `sky` + `sleephero()` right under the header, as App.tsx renders it): P01-Today-Night, P01-Edit-Night, P01-DaySheet-Night, P01-Desktop-Night. These are the only things TodayView changes while a night is live:

- the SleepHero band;
- the sleep-missing and auto-filled cards are hidden (they return null while a night is live; neither is on the default board);
- start controls go `disabled` (busy). None is visible on the default board, so nothing else changes.
- Assumption: SleepHero stays above the edit screen, because App renders it outside the screen. The styles.css rule for `td-editing` is not staged.

**Health colours** (the same as P10): illness = brass, active recovery = ok, injury = bad, rest = rest. Updated:

- week pill "sick" and calendar legend "Sick";
