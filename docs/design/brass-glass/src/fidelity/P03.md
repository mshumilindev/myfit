## Removed from the previous version (it was invented)
- Start sheet: the "Templates · 4 saved" row, the list layout, and the "One live session at a time…" line. The source has hero → "Or start from scratch" → a 5-tile grid (Auto session, Activity, Health, Log past, Home set).
- Session builder: the intent card sub-lines ("long rest", "Fast"), my "Chest is a grow-focus…" hint, and the "Auto" header link. Review had a readiness ring and "Length" seg, which don't exist there; the day-length seg belongs to the "The day" step.
- The coach "USUALLY FIRST · Bench press · Add" card and the "Add exercise" button. Neither is in SessionStartCoach.
- Quick log: a Pace stat card, a distance stepper, "Estimate · kcal" wording, "Ends now" shown on the wrong mode, and my own "Conditioning · last…" sub-line.
- Activity: the "Timer keeps going" banner, "Today so far", the route map, pace chart, heart rate, note and Edit/Delete pair (the saved view is an edit form), "Keep" / "Keep going" dialog labels and my dialog copy.
- Log activity: my subtitle under the title, "Load today" card on mobile (it's web-panel only), offline banner, skeleton, failed card, invented "kitesurf" search and the "Jump rope “running rope”" synonym row.
- Gym picker: "Favourite" tag, "Open now / Open 24/7 / Closed now" text, the close X and the bottom "Without a gym" button (it's a list row). The empty "No saved gyms yet" card is gone too; the picker has no such state.
- Controls: the RIR scale, RPE chips (set RPE is on P04), preset hour chips and the stepper duration picker.

- The data modules are now in the upload, so the mock values were corrected: intent rep ranges come from `INTENT_SPEC` (3–5, 6–12, 12–20, 3–6, 10–15), and home moves from `HOME_CATALOG` (Stomach Vacuum, Pullups, Pushups, Bench Dips, Bodyweight Squat, Plank, Chin-Up, Butt Lift (Bridge), Side Bridge).
- Night: when `nightLive`, the screen gets SpotterSky and SleepHero under the brand (mood='sky' + `sleephero()`). `liveSleep` also makes StartSheet / LogActivity / QuickLog locked.

## Production-ready pass (rule #0c)
**Colour coding, from the code**
- Activity category tone follows `views/logActivity/shared.ts` KIT_OF: Conditioning = accent/brass (`la-g`), Sports = sport (`la-s`), Recovery = rest (`la-r`). Every Run, Walk, Cycling and Rowing tile, badge, bar, calendar marker, pinned card, hero and LiveBanner is now brass (it was sport). Football and Tennis are sport; Sauna and Yoga are rest.
- The sleep LiveBanner is `la-r`, so it's rest.
- ActivityHead `.act-cat-badge` uses the category tone.
- Start sheet tile icons: Auto = gold, Activity = green (ok), Health = blue (rest), Log past = neutral.
- EffortGauge: LEVEL_COLOR = ok / accent / danger.
- Coach readiness %: READINESS_COLOR (ready ok, nearly accent, recovering danger). The banner tint follows severity (recovering → danger card).
- MonthCalendar markers and legend: accent / sport / rest.
- Builder day toggles: plain icons, no tone.

**Real visuals**
- Coach muscle strip: `MuscleIcon` → `bodymap(region crop)` per muscle.
- EffortGauge: level colours, filled up to the level, label in the level colour. See "Approximated" below.
- TimelineRange: track, range and two handles at the exact start/end.
- Calendars: real 6×7 month grids.
- No hatched placeholders except GymThumb. GymThumb is a runtime map/provider image with no local file, so it stays `photo()`.

**Images checked against the code**
- SessionStartCoach, SessionBuilderView and the StartSheet tiles render no exercise photos: rows are names/icons only, and the builder goal step uses `<Icon name="person">`, not the physique PNGs. So no exercise images were added there.
- `home-hero.webp` is used only by LiveHero and the home-set session (P01/P04), not by HomeSetSheet.
- Home move icons are HomeMoveIcon inline SVG paths (not assets). They're drawn with the nearest kit icon.

## Typeable times (owner requirement) + real gauge
- Every TimelineRange (Activity-Edit, -New-Past, -Delete, Controls) is now the kit `timerange()`: typeable start/end fields (`timein`) above the draggable track, with overnight wrap (Controls: 21:00 → 09:00). **Focused board:** P03-Activity-Edit (start field being typed); Controls also shows a focused end field.
- TimeField (Log past Start, Controls) = `timein` + the clock button that opens the hour/minute columns. The error example (23:40, focused) is on Controls.
- DurationField = two `timein` inputs (h · min). Quick log "Start" (earlier / pick a day / night) = `timein`.
- EffortGauge = the kit `gauge()`: a semicircle graded ok → accent → danger with the needle on the level, plus the Light/Moderate/Hard selector. The earlier "3-step meter" approximation is gone.
