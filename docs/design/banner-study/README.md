# To do: дослідження стека банерів

Інтерактивний прототип: Storybook → **Studies / To do · 20 concepts / Playground**.
Український редакційний контент — демонстраційні фікстури. Застосунок і його
збережені налаштування прототип не змінює. Публікацію в production не виконували.

## Як працює зараз

- `components/NudgeStack.tsx`: сортування за спаданням `priority`; верхня картка
  і два шари позаду, заголовок, категорія та іконка. Пояснення й дії — в оверлеї.
- Реальний інтервал ротації — **15 секунд** (`ROTATE_MS`), хоча коментар на початку
  файла описує ≥30 секунд. Ротація зупиняється поза екраном і під час перегляду.
- Натискання відкриває власний portal-оверлей, у якому всі картки йдуть за
  пріоритетом незалежно від поточної картки колоди. Фонова `.screen` блокується.
- `today/CoreConfigSheet.tsx`: тільки перемикачі категорій. `NudgesOpts` у
  `today/layout.ts` зберігає лише `off`; виду, щільності чи режиму ротації немає.
- `views/TodayView.tsx` формує рекомендації; окремі статуси та початковий банер
  навчання живуть поза стеком. Прототип охоплює саме стек, не всі статуси Today.
- Поточний оверлей має `role="dialog"`, але не використовує загальний `Sheet`.
  Нові варіанти використовують наявний `Sheet`, його закриття й прокручування.

## Що порівнюємо

Кожен із 20 напрямів має віджет, робочі налаштування та формат усіх банерів.
У режимі «Детально» всі три частини стоять поруч, на телефоні — послідовно.
Однакові 6 демонстраційних повідомлень, 1 повідомлення та порожній стан
дозволяють порівнювати структуру, а не різний контент. У налаштуваннях можна
окремо змінювати формат повного перегляду: картки, групи, по одній, акордеон,
чекліст, час або категорії. Дії симулюють проходження черги; записи не створюються.

Візуальна база: Card, Banner, GroupedList/ListRow, IconTile, Button, Chip,
Segmented, OptionCard, Switch, SectionLabel та Sheet. Нових кольорів чи
альтернативних компонентів не додано. CSS у `redesign.css` задає лише композицію.

## Рекомендований напрям

**03 «Вхідні»** — базовий: жодної автоматичної зміни, три справи читаються
одночасно, помірна висота. **10** — якщо потрібна одна головна дія без втрати
видимості наступних. **20** — якщо кількість повідомлень сильно коливається;
перед впровадженням варто перевірити, чи зміна композиції не дезорієнтує.
**01** — для максимально простого віджету з одним пріоритетом.

У production варто залишити 3–4 названі види, а не всі 20. Повний перегляд за
замовчуванням — групи «Зараз / Пізніше», згорнуті другорядні повідомлення.
Категорії залишити наявними; нові візуальні налаштування додавати в `NudgesOpts`
лише після вибору дизайну. Часові групи та «виконано» потребують окремих
доменних правил: приховати підказку не означає виконати дію.

## Перевірка прототипу

- Storybook зібрано; TypeScript і ESLint — без помилок (є попереднє попередження
  у `atlas/useTodayPlan.ts`, поза цими змінами).
- Загальні тести з покриттям та SQL-гейт пройшли; змінені файли відформатовано.
- У браузері перевірено 20/20 діалогів на 390 та 1280 px, Escape, перемикання
  щільності, вимкнення категорії, стани з 0 та 1 повідомленням.
- Збережено прев’ю в `previews/`: огляд трьох частин, мобільні модалка й налаштування.
