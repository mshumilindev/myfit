# Іконки стору (SPO-556)

Рішення (11.11.2026): джерела іконок стору живуть тут, у репозиторії.

- `blender/` — генератор (`gen.py`, `real.py`, шрифти, текстури тем; `blender/README.md` — як запускати: `bpy==5.2.3`, Cycles CPU, 640 px). Стиль «Paper + фотореалістичні предмети», усі 19 іконок: `python3 gen.py out s12`.
- Готові картинки: `client/public/store-icons/<id>.webp` (320×320, плитка заповнює весь кадр), `<id>` = id з маніфесту.
- Стиль і вимоги: `.claude/rules/addons.md`, п. 12.

Нова іконка: додати елемент в `ITEMS` у `gen.py` (глиф і тон), згенерувати, обрізати плитку на весь кадр і зберегти webp 320 у `client/public/store-icons/`; зміни `gen.py` комітяться разом із webp. Тест `storeInfo.contract.test.ts` падає, якщо іконки немає.

Примітка: окремий пілот «soft clay» (`~/Desktop/Work/training/icons-3d/`) — інший стиль, до стору не підключений.
