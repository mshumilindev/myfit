# Іконки стору (SPO-556)

Рішення (11.11.2026): джерела іконок стору живуть тут, у репозиторії.

- `blender/` — скрипти `bpy` (Blender headless, Cycles CPU) і `.blend`-сцени. Кожна нова іконка апка, аддона чи теми додається сюди скриптом, а не вручну.
- Готові картинки: `client/public/store-icons/<id>.webp` (320×320, плитка заповнює весь кадр), `<id>` = id з маніфесту.
- Стиль і вимоги: `.claude/rules/addons.md`, п. 12 (Paper + фотореалістичні предмети, колір плитки під зміст аддона, перевірка на 176…24 px).

## Чесний стан

Скрипти, якими зроблено перші 19 іконок (11.11.2026), до репозиторію не потрапили: в архіві були лише PNG 640×640, джерела лишилися в чаті-генераторі. Отже, зараз у `blender/` немає джерел цього набору. Пілотний «soft clay» генератор лежить окремо в `~/Desktop/Work/training/icons-3d/` (інший стиль, до стору не підключений).

Правило для наступних іконок: скрипт і `.blend` комітяться в `blender/` одночасно з `webp`.
