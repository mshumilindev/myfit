# My Fit (gym-tracker) — правила для агентів

Особиста фітнес-платформа: ФЕ (React PWA) + BFF (Express + SQLite) + Electron-трей.
Скоуп продукту: `docs/MVP.md`. План робіт: `docs/DEV-PLAN.md`.

## Правила (обов'язкові, лежать у `.cursor/rules/`)

| Файл                 | Про що                                                          |
| -------------------- | --------------------------------------------------------------- |
| `agent-approach.mdc` | Як досліджувати, рекомендувати і чесно звітувати                |
| `stack.mdc`          | Зафіксований стек і анти-патерни                                |
| `architecture.mdc`   | Shell + сервіс-модулі, API-межа, офлайн-черга, помилки, нейминг |
| `quality-gate.mdc`   | Lint / format / typecheck / тести перед push                    |
| `test-integrity.mdc` | Тести — контракти; заборонені шляхи до зеленого                 |

## Швидкі команди

```bash
npm run dev          # server :4477 (tsx watch) + client :5173 (vite HMR)
npm run typecheck    # tsc у всіх трьох воркспейсах
npm run lint         # ESLint по репо
npm run format:check # Prettier без запису
npm run build        # server + client + desktop
GYM_DATA_DIR=$(mktemp -d) PORT=4499 npm run start -w server &
BASE=http://localhost:4499 node scripts/smoke.mjs   # API-смоук на тестовій БД
```

## Три інваріанти, які не можна зламати

1. **Сервер — єдине джерело правди.** Клієнт пише в офлайн-чергу, синк повністю
   заміняє локальний кеш станом сервера.
2. **Ідемпотентність.** Всі id генерує клієнт (UUID), записи йдуть через upsert —
   повторна відправка черги безпечна.
3. **Правила тренування** (одне відкрите; авто-закриття через 8 год з позначкою ⚠️)
   діють однаково на сервері і локально офлайн.

## Дизайн і мова

- Джерело правди UI — дизайни Claude Design: див. `docs/DESIGN.md` і інвентарі
  в `docs/design/`. Реалізація слідує макетам на 100%; відхилення документуються.
- UI — i18n на 5 локалей (en база з макетів, uk, pl, lt, et) у `client/src/i18n/`.
  Новий рядок додається одразу в усі п'ять словників (тип `Strings` це ловить).
- Коміти й доки — українською. Код — англійською.
