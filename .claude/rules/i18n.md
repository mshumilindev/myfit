# i18n: 5 локалей, жодних літералів

- Усі тексти UI — через словники `client/src/i18n/` (en — база з макетів; uk, pl, lt, et). Жодних рядкових літералів у компонентах, у т.ч. повідомлень про помилки: користувач бачить зрозумілий локалізований текст без стеків, URL і сирого тексту бекенда.
- Новий рядок — одразу в усі п'ять словників; тип `Strings` з `en.ts` робить пропуск помилкою компіляції. Плюрали — локальні хелпери; дати/числа — форматери `i18n/index.ts`.
- Довгі слова (pl/lt/et) не ламають верстку: бюджети в `tests/i18n-length.test.ts`. Бюджет не піднімаємо й винятків не додаємо — скорочуй переклад.
- Перевірки: `npm run i18n:check`, `tests/i18n*.test.ts`, `client/src/i18n/*.test.ts` (паритет, у т.ч. coach-словники).
