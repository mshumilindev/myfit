# Фікс верстки без повторів

1. **Відтвори і виміряй:** скрін + геометрія (Playwright), CLS через `PerformanceObserver`. Без відтвореного симптому не фіксимо.
2. **Корінь, не симптом:** питай «чому» до причини; якщо причин кілька — назви всі.
3. **Знайди всі місця:** `rg` усіх споживачів спільного (кіт, глобальний CSS) і схожих екранів — баг рідко єдиний.
4. **Фікс у кіті:** проп/варіант примітива, а не оверрайд на екрані. Оверрайд лише layout, один селектор, коментар «чому», у `glass.css`/`redesign.css`.
5. **Захист:** спершу перевірка в `scripts/*-audit.mjs` (або guard-тест), що падає на багу, потім фікс; нова сторі для стану.
6. **Докази:** скрін/замір до й після (390 і 1280), аудити по змінених сторі = 0, `kit-guard` і `hygiene-ratchet` зелені.
7. **Звіт користувачу:** що саме виправлено й де перевірити руками. Не пиши в БД з акаунта користувача.
